# 统一设定对比

[English](README.md) | [简体中文](README_zh.md)

[examples/reproduction/](../reproduction/) 中复现的论文使用不同的基座模型、训练集、基线定义和评测协议，其中有几篇还沿用了其他论文的基线数字，因此它们报告的提升很难相互比较。下面每个对比都用**同一套**设定训练一类方法：相同的模型、数据、超参数和评测。每个目录中的脚本只设置 `ALGO_ARGS`，即定义该方法的开关；其余配置都来自该目录的 `common.sh`。

| 对比 | 方法 | 统一设定 | 结果 |
| --- | --- | --- | --- |
| [Qwen3-VL-4B-Instruct 上的 RLVR 对比](rlvr_qwen3_vl_4b/README_zh.md) | GRPO 和 DAPO 基线；PAPO、VPPO、ToR、DVRP、PGPO、PEPO、CFPO、VEPO、NoisyRollout、VGPO、VAPO、GRIT、CGPO | ViRL39K，202 步，每步 384 道题 × 8 个回答，GRPO 超参数，4 张 A800 | 三组共 19 项基准，最后一步和验证最优步；训练时长 |
| [Qwen3-VL-2B-Instruct 上的 OPD 对比](opd_qwen3_vl_2b/README_zh.md) | GRPO 参照；基于采样 token 的 OPD、基于完整分布的 OPD、VA-OPD、VGS、VCSD | 沿用 RLVR 对比的数据、提示词和长度；以经 GRPO 训练的 Qwen3-VL-4B-Instruct 为教师；606 次更新，每次 1,024 个回答，4 张 A800 | 同样的 19 项基准，最后一步和验证最优步；训练时长 |

DeepEyes（RLVR）和 Vision-OPD（OPD）不在这两个对比中，原因见各对比的 README。

## 关于结果的说明

> [!IMPORTANT]
> **这些结果仅供参考，不作为对方法本身的评判。** 用本仓库得到的数字（上面各对比的表格，以及各复现 README 中标注为本仓库的列）有以下局限。

- **非官方复现。** 除 CGPO 外，所有方法都由我们依据论文（以及已公开的官方代码）重新实现。论文未写明的细节可能与作者代码不同，已知差异列在各方法的 README 中。
- **环境不同。** 硬件、软件版本（PyTorch、vLLM、transformers、强化学习框架）和数据预处理都与原论文不同。
- **每个方法只跑一次。** 训练本身并不确定（采样、算子、硬件），而每个配置只训练一次。RLVR 对比中同一配置的 CFPO 跑了两次（第二次用了一个更快的反事实注意力实现，与第一次只有舍入误差的差别），三组平均相差 0.6，单项基准最多相差 2.6，两个方向都有；而同一次运行中相隔五步的两个检查点只差约 0.15。方法之间一个点左右的差距都在这一波动范围内，许多论文报告的提升也在这个量级。
- **统一设定并不是各方法自己的设定。** 同一个对比中的所有方法使用同一个基座模型、同一份数据、同样的训练量、同一组超参数和同一个提示词。大多数方法是为另一种设定（不同的模型、数据、基础算法、回答长度或训练日程）设计和调参的，部分组件也没有使用（见各对比的“方法”一节）；一个方法在这个设定下未必能发挥最佳性能。
- **评测协议是本仓库的。** 所有检查点都用本仓库的评测框架和提示词评测，与各论文的评测方式不同。

这些表格只描述我们的复现在这些设定下的表现，不是对方法的排名，也不能作为支持或否定任何方法的证据。各方法的性能请以原论文为准。如果您是原作者，发现我们的实现或设定有问题，欢迎提交 issue 或 PR，我们会修正。
